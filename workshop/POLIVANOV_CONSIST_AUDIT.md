# Аудит перевода 1.2: Поливанов и консистентность

Отчёт (без внесения правок). Проверено по рабочему дереву `woh-translation`
(ветка `update-1.2` + незакоммиченная нормализация кавычек).

## 1. Новые персонажи 1.2 — транслитерация по Поливанову

| Русский | Японский | Чтение | Вердикт |
|---|---|---|---|
| АЙКО ТАКАХА**Ш**И | 高橋 愛子 | Takahashi Aiko | ❌ Хэпбёрн → **ТАКАХАСИ** (し = си) |
| ТО**Ш**ИАКИ ВАКАМАЦУ | 若松 俊明 | Wakamatsu Toshiaki | ❌ Хэпбёрн → **ТОСИАКИ** |
| ЯСИРО КАВАДЗИ | 川地 八代 | Kawaji Yashiro | ✅ (но возраст: рус. 24 vs яп. 26歳) |
| КИРИКО ЁСИЯ | 吉谷 霧子 | Yoshiya Kiriko | ✅ |
| САТОСИ МУРАМАЦУ | 村松 聡 | Muramatsu Satoshi | ✅ |
| МАКОТО ЯМАУТИ | 山内 真琴 | Yamauchi Makoto | ✅ (ち = ти, верно) |

**Итог:** из новых имён два нарушают Поливанова — **ТАКАХАШИ** и **ТОШИАКИ**
(し передано как ШИ вместо СИ). Остальные корректны.
Отдельно у ЯСИРО КАВАДЗИ — несовпадение возраста (24 против 26歳).

## 2. Имена по всему переводу — системы смешаны

Те же нарушения し→ШИ / ち→ЧИ / ず→ЗУ встречаются и в старых именах, то есть
единый стандарт не выдержан:

| Сейчас | Японский | По Поливанову |
|---|---|---|
| МОРИКО И**Ш**ИИ | 石井 | ИСИИ |
| ЮМИКО И**Ч**ИМУРА | 市村 | ИТИМУРА |
| ХИРОКИ **Ш**ИНОХЕ | 篠瀬 | СИНОХЭ |
| ХИРОЮКИ МИ**З**УТАНИ | 水谷 | МИДЗУТАНИ (ず = дзу) |
| МИ**З**УКИ ХАМАСАКИ | 濱崎 瑞希 | спорно: МИДЗУКИ |
| 淳平 ДЗЮ**М**ПЭЙ / ДЗЮ**Н**ПЭЙ | 淳平 | ДЗЮНПЭЙ (ん = н), и разнобой |

При этом КОДЗИ, КАВАДЗИ, ЯМАУТИ, САТОСИ, ЯСИРО — уже по Поливанову.
→ Нужно привести все имена к одной системе.

**Исключение:** ШИОКАВА (塩川). Строго по Поливанову — Сиокава, но написано
одинаково по всему переводу — вероятно, намеренно устоявшееся название города.

## 3. Консист: один японский термин → разные русские (34 расхождения)

## Примечание о методе
Имена искались по профилям персонажей (яп. «ФАМИЛИЯ ИМЯ» + 歳 / рус. «Имя:»).
Консист — по совпадению японской стороны при разной русской (короткие термины,
без переносов `#`). Список выше — кандидаты для сверки; окончательное решение
по каждому (транслит vs перевод, какой вариант канон) — за командой перевода.
