# Подготовка страницы Steam Workshop — русификатор WORLD OF HORROR

Документ собран для публикации русификатора в мастерской Steam
(appid **913740**). Задача: перевести раздачу с «скачай zip из VK/Telegram
и подложи руками» на «подписался в мастерской — Steam сам качает и обновляет».

Статус: каркас готов. Окончательную сборку делаем **в понедельник**, когда
автор обновит файлы перевода, затем сверяем правки.

---

## 1. Как на самом деле устроена локализация в WOH (важно)

Проверено по бинарникам игры 1.2 (`worldofhorror.exe`, `data.win`):

- **Языковые папки захардкожены в exe.** В exe присутствуют строки:
  `engLanguage, chsLanguage, chtLanguage, japLanguage, korLanguage,
  fraLanguage, gerLanguage, polLanguage` и даже пока неиспользуемые
  `ukrLanguage, turLanguage`. **Строки `rusLanguage` нет.**
  → Добавить «русский» как новый язык, просто положив папку, нельзя.
  Поэтому перевод исторически кладётся в слот **engLanguage** (заменяет
  английский).

- **Язык читается только из папки установки игры**
  (`...\common\WOH\language\<код>Language\`), а **не** из папки предмета
  мастерской (`...\steamapps\workshop\content\913740\<id>\`).
  → Подписка сама по себе перевод не включает: игра не читает .jn из папки
  мастерской. Нужен шаг копирования в игру (вручную или установщиком).

- **Шрифты и картинки** зашиты в `data.win`. Чтобы их заменить, нужен
  UndertaleModTool и ручная пересборка `data.win` (см. README репозитория).
  Через мастерскую это раздать нельзя — поэтому предмет мастерской несёт
  **только текст (.jn)**.

- **У WOH есть встроенный публикатор мастерской.** В `data.win` присутствует
  полный набор функций GameMaker: `steam_ugc_create_item`,
  `steam_ugc_start_item_update`, `steam_ugc_set_item_content`,
  `steam_ugc_set_item_preview`, `steam_ugc_set_item_title`,
  `steam_ugc_set_item_description`, `steam_ugc_set_item_tags`,
  `steam_ugc_set_item_visibility`, `steam_ugc_submit_item_update`.
  → Так были выложены 313 предметов мастерской. Это основной путь публикации
  (см. §4A). Альтернатива — steamcmd (§4B).

**Вывод по модели раздачи.** Предмет мастерской = канал доставки и
авто-обновления. Внутри — папка `language` (файлы .jn). Пользователь
подписывается, а затем копирует `language` в игру (руками или нашим
`install.bat`). Это уже заметно удобнее внешних ссылок: Steam сам качает и
обновляет.

### Проверено: «подписался и играешь» — НЕВОЗМОЖНО для базового русификатора
Разбор бинарников игры 1.2:
- Базовый текст игры грузит **exe**: в `worldofhorror.exe` захардкожены пути
  `language/<код>Language` (все 9 языков) и имена файлов `woh_*.jn` (27 ссылок
  на `.jn`). Игра читает язык **из папки установки**, а не из папки мастерской.
- В `data.win` (логика игры) **нет ни одной** ссылки на `.jn` или `language`.
  Загрузчик мастерской там (`steam_ugc_get_item_install_info`) подхватывает
  только кастомный контент (персонажи/события/враги/тайны), но НЕ языковые файлы.

Вывод: подписанный предмет лежит в `workshop/content/913740/<id>/` и как язык
никогда не читается. Авто-режим был бы возможен только если патчить exe (а его
через мастерскую не раздать) или если разработчик добавит в игру нативную
поддержку языковых паков из мастерской. Пока — только **подписка + копирование**
(вручную или `install.bat` / `install.sh`).

Отдельно: часть строк вшита прямо в exe (их и правит «логика подмены строк»
автора) — такие строки .jn-файлами не меняются вообще, нужен патч exe. Для
текстового предмета мастерской это вне охвата (несём только .jn).

## 2. Содержимое предмета мастерской

Папка контента, которая уходит в мастерскую (собирается скриптом из §4):

```
content/
  language/
    engLanguage/
      woh_*.jn          # все файлы перевода из translation/language/engLanguage
  install.bat           # опциональный установщик: находит WOH и копирует language/
  ЧИТАЙ_МЕНЯ.txt         # краткая инструкция
```

Фонты/спрайты НЕ включаем (см. §1).

## 3. Метаданные страницы

| Поле | Значение |
|------|----------|
| **Название** | `Полная русская локализация (Russian localization)` |
| **Превью** | квадрат, ≤ 1 МБ, .png/.jpg. Рекомендую 512×512 или 1024×1024. Кандидат: лого игры + надпись «РУСИФИКАТОР». Готового промо в репозитории нет — сделать/подобрать (можно взять `img/s_graphicscustom_*` как основу). |
| **Видимость** | Public (после проверки — сначала можно Hidden/Friends для теста) |
| **Описание** | см. `description_ru.txt` (готово, BBCode) |
| **Теги** | мастерская WOH фильтрует по типам контента (Characters / Events / Enemies / Mysteries). Русификатор под эти типы не попадает — выставить общий/нейтральный тег, в названии и описании явно указать «локализация/русификатор», чтобы находили поиском. Уточнить доступные теги в окне публикации. |
| **Язык страницы** | русский |

## 4. Как опубликовать

### 4A. Встроенный публикатор игры (рекомендуется — так принято в WOH)
1. Разложить контент как в §2 (запустить `build_and_upload.ps1 -NoUpload`,
   он только соберёт `content/`).
2. В игре открыть раздел модов/мастерской и создать новый предмет, указав
   папку `content/`, превью, название, описание, видимость.
3. Опубликовать. Steam выдаст **PublishedFileID** — записать его в `item.vdf`
   (поле `publishedfileid`) для последующих обновлений.

### 4B. steamcmd (для повторяемых обновлений из консоли)
Нужен уже созданный предмет (его `publishedfileid` из §4A: steamcmd сам
создавать предмет для чужого appid обычно не даёт).
1. Собрать контент: `build_and_upload.ps1 -NoUpload`.
2. Проверить `item.vdf` (appid 913740, путь к `content/`, превью, publishedfileid).
3. Загрузить:
   ```
   D:\steamcmd\steamcmd.exe +login <аккаунт> +workshop_build_item "D:\1\mi\woh-translation\workshop\item.vdf" +quit
   ```
   или просто `build_and_upload.ps1` (без `-NoUpload`).

## 5. Рабочий процесс на понедельник
1. Автор коммитит обновлённый перевод в `translation/language/engLanguage`.
2. `git pull` / сверить мои правки (ветка `update-1.2`) с версией автора:
   - моя правка перевода: `woh_shichi.jn` — `(LMB)/(RMB)` → `(ЛКМ)/(ПКМ)`
     (новая строка 1.2 про закрепление тайны). Подробности — в
     `TRANSLATION_REVIEW.md`.
3. Прогнать `build_and_upload.ps1 -NoUpload`, проверить `content/`.
4. Способ установки — подписка + копирование (см. §1, авто-режим невозможен).
5. Опубликовать (§4A), сохранить PublishedFileID в `item.vdf`.
6. Вставить `description_ru.txt`, превью, теги, выставить видимость.
