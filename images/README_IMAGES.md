# Картинки и шрифты: патч data.win — ПРОТОТИП

Ставит переведённые **картинки и шрифты**, патча `data.win` на машине
пользователя. `data.win` сам не раздаётся — везём только `img/` и `font/`.
Работает на Windows, Linux и Steam Deck.

> ⚠️ **Прототип.** Логика написана по API UndertaleModTool, но на живом
> `data.win` мной не прогонялась. Всегда делается резервная копия
> `data.win.orig_backup`. Проверяйте на копии.

## Как запускается
Обычно **через установщик**: `install.bat` / `install.sh` после текста
спрашивают, применять ли картинки/шрифты, и вызывают патч сами.

Напрямую:
```
# Windows
powershell -ExecutionPolicy Bypass -File patch_images.ps1
# Linux / macOS / Steam Deck (Desktop Mode)
bash patch_images.sh
```

## UndertaleModCli скачивается сам
Если `UndertaleModCli` не найден (в `UMT_CLI`, в PATH или в кэше `images/.umtcli/`),
скрипт **сам скачивает** нужную self-contained сборку из последнего релиза
UndertaleModTool и кладёт в `images/.umtcli/` (в git не коммитится). .NET ставить
не нужно. Чтобы использовать свою сборку — задайте путь в `UMT_CLI`.

## Как работает патч
`woh_patch.csx` для каждого PNG находит спрайт по имени `имя_<кадр>.png` и
заменяет этот кадр «на месте» через `UndertaleTexturePageItem.ReplaceTexture`
(как ручной Import на текстуре в GUI). Атласы не переупаковываются, экспорт не
нужен. Шрифты (silver_vsmall/small/big) заменяются так же. Если скрипт печатает
«не найден спрайт/фон для: …» — имя PNG не совпало с ресурсом, разобрать вручную.

## Проверка перед раздачей
1. Скопировать `data.win`, прогнать патч на копии.
2. Открыть копию в UndertaleModTool (GUI), глазами проверить спрайты и шрифты.
3. Запустить игру с пропатченным `data.win`, убедиться, что всё на месте.

Ручной путь (GUI), если что-то не так, — в README основного репозитория перевода.

## Про Steam Deck
Нативной Linux-версии нет; игра идёт через Proton, но `data.win`
платформонезависим. Патч тяжёлый (data.win ~314 МБ) и небыстрый; запускать из
Desktop Mode. После обновления игры патч откатывается — прогнать заново.
